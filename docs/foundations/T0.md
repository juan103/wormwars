## 1. Compute accounting

**What happens now.** `evolve` reports `evaluations` as strain-worlds used for *selection* only.
Holdout checkpoints, snapshot checks and the final re-evaluation that picks the champion are not
counted. Probes, calibration and experiment-level measures are not counted at all.

**The plan.** A small ledger module, `wormwars/accounting.py`, with two choke points:
- **World simulation:** `evo.rollout._play`. Every rollout and scripted controller goes through it,
  and it records strain-worlds and world ticks. A test checks that no other code builds a `World`
  outside `_play`. Anything that does (the calibration probes, for example) either routes through
  it or records explicitly, and the test lists those call sites.
- **Neural updates:** `Brain.step` counts strain × substep updates, wherever it is called,
  including the input-response and history probes, which do not use the world.
- **Categories:** a context manager tags each record, as in `with ledger.category("holdout"):`. The
  categories are selection, holdout, snapshot, final, calibration, probe, tuning and other.
- **GPU-seconds:** wall time per category, measured with `torch.cuda.synchronize()` at category
  boundaries only, so the hot loop is not slowed.
- **Output:** `evolve`'s `RunResult` gains a `compute` dict by category. The old `evaluations` field
  is kept unchanged (selection only), so existing records stay comparable, and is documented as
  such.
- **Test:** counts from the ledger equal counts computed by hand for a small run. That covers
  population × worlds × generations, plus the holdout, snapshot and final evaluations.

## 2. Genome and score pairing

- **Order:** evaluating a population and the same population in permuted order gives the same
  per-strain scores, permuted identically.
- **Chunking:** results are identical for any `chunk_worlds`, which changes how strains are
  split into chunks.
- **Evolution:** in `evolve`, the logged best score belongs to the strain whose genome is logged,
  and re-evaluating that genome alone on the same worlds reproduces it.

## 3. Complete inheritance

- **Every parameter field survives every operation:** `select`, `mutate` (unmutated fields
  unchanged), `breed` (elites and children), `_breed_islands`, `_migrate`, and save and load.
- **The test enumerates `Genome`'s tensor fields itself,** so a field added later fails the test
  until it is covered.

## 4. Save, load and replay

- **Deterministic mode (CPU):**
  - saving a genome, loading it, and replaying on the same world ids and run seed reproduces the
    per-strain scores **exactly**;
  - loading a champion saved by an old run and replaying it reproduces the score recorded in its
    log, where the log recorded one for those world ids.
- **Tolerance for other modes (CUDA), declared before measuring:** per-strain score agreement
  within **1e-4** absolute. If a measurement exceeds it, the result is recorded, and the tolerance
  is not widened silently: that would be a finding.

## 5. Energy ledger and numerical checks

- **Energy ledger:** the rollout's `ledger_error` must stay below a declared bound (to be fixed from
  the current code's documented tolerance) on a test suite of worlds, for N2, SH and RD.
- **Numbers:** no NaN or Inf in scores, energies or brain states over a full episode, for random
  genomes at the mutation bounds.
