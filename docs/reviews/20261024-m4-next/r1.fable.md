**Ranked risks, and what the plan must fix:**

1. **Density confound.** C3 has 260 internal chemical edges; reference graphs keep 97 to 121 among those neurons (M4a). Inserting C3 more than doubles local density and weight, and any heavy recurrent block may be bistable. Without a C3-rewired-within-at-fixed-degrees control and a weight-permuted control, a positive screen says only "a dense N2 block works". That is still useful, but it changes what M5 transplants.

2. **Host baseline and power.** Reference base rate is 38 of 29,315 (19 of 30 graphs have none); N2 is about 1.4%. Use fresh sampler draws, never the selected graphs (12 to 78 switches already). Several hosts per ensemble, at least 1024 genomes per arm, primary measure the count of full-state separate-states genomes per host and arm, each host against its own intact count and its rewired control. Fix the rule now (which arms, how many hosts must respond).

3. **Write, hold, read.** Keep the block on its own neuron identities: the sensory members and the eight read-out neurons are inside C3, so the host delivers the ramp and M2's full-state classifier (read-out-silent subclass included) is the independent observer. Record the block's separation at ramp end so "not written" is separable from "not held". "Placement away from the read-out" is a secondary arm, uninterpretable without that write measure.
