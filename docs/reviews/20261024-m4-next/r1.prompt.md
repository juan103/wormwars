**Where things stand.** The memory roadmap is `docs/memory/MEMORY-ROADMAP.md` (M4 and M5 sections; M4's plan items
include an exploratory transplant screen whose output is "the smallest successful structure among those tested", and
M5 is the pre-registered transplant test into independently generated hosts). M4a, M4b and M4c are done
(`docs/memory/M4A-RESULTS.md`, `M4B-RESULTS.md`, `M4C-RESULTS.md`; D358, D360, D362). In short: cutting N2's head core

- (d) Something else, or stop the thread here and write up M1 to M4.
