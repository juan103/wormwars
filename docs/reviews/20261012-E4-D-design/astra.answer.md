**Verdict: revise.** The task is salvageable, but v1 does not establish transfer necessity. I would make a fresh, first-choice assay primary and retain repeated shuttle visits as a secondary performance measure. This review checked the code and D245–D248; no experiments were run.

1. **Critical — “goal B” does not mean A’s output gate is closed.**  
   [`MazeWorld`](D:/Claude/random/wormWars/wormwars/e3/maze_world.py:408) changes the goal immediately after movement; [`Brain.step`](D:/Claude/random/wormWars/wormwars/brain.py:478) gates using q’s sign before each neural substep. D247 explicitly records switches following visits by one tick. Switching A’s input using `goal == B` can therefore feed the cue into A while its motor edges remain active. Moreover, A’s cue-dependent state can reach the motors when its gate subsequently reopens, even after the cue is removed. **Fix:** specify timing at substep resolution. For the necessity assay, introduce a fresh assignment only after A’s gate has closed, ensure it stays closed through the decision, and stop scoring at first candidate entry. Merely selecting the channel using q once per tick is insufficient across a within-tick gate transition.

2. **Critical — repeated B-legs do not have a half-chance bound.**  
   The assignment persists throughout an episode. Real-B contact supplies `at_b → RB → Q`; decoy contact does not. [`_extra_signals`](D:/Claude/random/wormWars/wormwars/e3/maze_world.py:374) exposes occupancy levels regardless of the current goal, so even contact **before the first A visit** can reveal the assignment. Later legs inherit identity-dependent latch state, neural transients, position, heading and travel history. A sufficiently persistent searcher can also visit both candidates without transferring anything. I am not claiming the present X0 learns this efficiently; the information-theoretic exclusion is already broken. **Fix:** use fresh, independently assigned single-choice trials with no earlier identity exposure, or redraw independently for each properly isolated decision. Visits over H have no universal “chance” value.

3. **Important — the remaining paths need explicit closure, not a blanket “no trails” claim.**  
   My code audit finds:
   - B’s summed scent, wall reflex and geometry supply navigation information, but cannot identify an independently assigned label before feedback.
   - Geometry, candidate ordering, spawns, headings and redraw selection can become predictors if any depend on which candidate is real. Construct everything first, then assign identity independently.
   - The silent carrier’s chemical/gap weights are zero and frozen; A’s non-cross-link exits are the gated motor edges. This supports isolation **while that gate remains closed**, not across an episode.
   - Peers appear excluded under the intended configuration: trail access is none, crowd resistance/push are zero, pheromones and energy costs are off, and combat is inactive. `access="none"` suppresses trail sensing; it does not stop trail deposition.
   
   **Fix:** assert these configuration, interface and connectivity conditions. Check all injected currents for unintended identity exposure, including derived `goal_*` signals. A single-wey diagnostic would simplify the exclusion substantially.

4. **Important — the placement description does not match the maze family.**  
   [`islands.py`](D:/Claude/random/wormWars/wormwars/e3/islands.py:121) selects interior goal pairs without requiring dead ends and opens additional segments around them. Consequently, `k_r=0` is still generally cyclic; there need not be a unique branch point. Adding an ordinary third dead end also does not give it the existing goals’ island treatment. **Fix:** define the actual three-site generator and constraints on the final carved graph. Either abandon the unique-branch wording and score first candidate entry, or construct an explicit decision junction. Declare distance units: graph cells and scent-grid cells differ. The scent is truncated at reach 9 by default; distance balance alone does not ensure an actionable cue near the decision.

5. **Critical — chance follows from exchangeability, not geometric symmetry.**  
   With a fresh fair label independent of the complete accessible history, X0 has exactly ½ expected accuracy **conditional on entering a candidate before feedback**, even with unequal route lengths. Including “neither,” its unconditional real-first rate is at most ½. Repeated legs and identity-dependent prior histories invalidate that argument. **Fix:** evaluate both assignments from identical starting states for each maze, with canonical candidate ordering. Report real-first, decoy-first and neither over all assigned trials; do not pool selectively completed legs. The proposed “X+ exceeds X0 by 0.2” alone is insufficient: improving from frequent timeouts to below-half real-first performance need not demonstrate target information.

6. **Important — multiplexing A’s noses is acceptable, with a narrower conclusion.**  
   I would retain the existing noses for this diagnostic, provided findings 1–2 are fixed. It tests whether the existing four-neuron modules and cross-links can convey an externally supplied target-directed signal. It does not show that A discovers the target or supplies useful information under E4’s ordinary inputs. A separate A-only channel makes cue manipulation cleaner and can preserve A’s ordinary scent, but changes the sensory interface; adding neurons changes the architecture further. **Neither option fixes the timing/history leaks automatically.** Specify exactly which neurons receive the separate input if that option is chosen.

7. **Important — the invariance and control requirements need rewriting.**  
   Whole-rollout cue-reversal invariance is not justified because A eventually regains motor access. Conversely, changing the real target need not change X0’s trajectory before contact—or ever if neither target is reached. “Swapping the walls’ real B” should mean changing target identity while holding walls fixed. **Fix:** require bitwise equality of X0’s motor commands, trajectories and non-A neural states through the first-choice boundary under cue-only reversal. Separately test identity-only reversal up to contact. Shuffle the **candidate identity within the same geometry**, independently of truth; an unrelated maze’s scent changes navigation structure. Shuffling need not reproduce X0’s visits: uninformative cross-link drive can still alter locomotion. Cross-link removal should reproduce X0 exactly if the two genomes otherwise match. Include cue removal, which v1 does not specify.

8. **Important — feasibility is not yet fixed tightly enough.**

Keep calibration separate. Retain the proposed 0.2 improvement if desired, but additionally require above-half real-first performance over all trials, with a specified maze-level uncertainty criterion. Define a meaningful visits margin if visits remain mandatory. State pass criteria for shuffled and removed cues, not merely list them. Failed evaluation followed by changes requires a declared new version and fresh evaluation block.
