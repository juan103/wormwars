**Verdict: revise.** The ladder, the host design, the no-floor outcome and the reading are sound. One construction is inconsistent as written, one control is missing, and three smaller points follow.

**Findings, ranked**

1. **The sham cannot be exact as written.** Block-edge signs come from a fresh 30×30 matrix, `default_rng(20261211 + host)`. In arm I, the host's own block edges carry the signs `Genome.random` drew in edge order at `wormwars/brain.py:218`. So the rebuilt sham matches `Genome.random` with probability 2^-100, and an edge at a position the host and N2 share has different signs in I and T, contrary to the plan's claim. Fix: define the sign matrix as the intact genome's signs where the host has a block edge, fresh draws elsewhere. Also fix the divisor as the intact spec's float32 `chem_anat.mean()`, not a recomputed mean, or the exactness test fails on the last bit.

2. **Reciprocity is uncontrolled.** C3 has 75 reciprocal pairs. At density 260 of 870, random placement expects about 39. R destroys this, so a T over R win is equally "N2's wiring" and "twice the two-cycles". Since M4's own dissection list names "reciprocal pairs broken" and SH-recip's acceptance test already exists, add an R-recip arm at fixed degrees and fixed reciprocal count, about 2.4 CPU hours, or state the limit in the positive reading. Also, R's "strengths" claim is half true: a swap carrying weights with edges preserves one of in- and out-strength, not both.

3. **The bootstrap double counts.** Host means already carry within-host binomial noise, so resampling genomes within hosts as well widens the interval. For "positive" this is conservative. For "dense block" and "no effect", which need an upper bound below 0.004, it pushes results toward "unresolved". Resample hosts only, or state the conservatism.

4. **The "read" measure is amplitude-dependent.** `scripts/memory_m2/classify.py:123` splits the subclasses by read-out difference against 0.1·a. Without the floor, low-a genomes almost never read "silent". The primary measure is unaffected, but report the silent share among genomes above `START_FLOOR`, or use an absolute threshold.

5. **The companion's skip clause is unnecessary.** M4c's switch ids are in the committed records, `runs/memory-m4c/census/N2__780x.json`, class per genome, and the genomes regenerate from seeds 7801 to 7808. The npz arrays are an integrity check at `m4c.py:313`, not an input.
