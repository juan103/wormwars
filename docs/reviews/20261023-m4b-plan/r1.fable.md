**Verdict: revise.** The code does what the plan says; the plan claims more than Q2's design can show, and two things should be fixed before the hour runs.

1. **Q2's control cannot fail the way the own cut can, by construction.** An edge with both ends outside the top-30 removes nearly the same input in both histories, because its presynaptic neuron sits at almost the same value in both roots. Such a cut erases only by pushing the shared state across a basin boundary. The own cut removes inputs that differ between histories, attacking the difference directly. So D > 0.10 is the expected result in any graph where chemical recurrence among the differing neurons carries the difference, and it does not discriminate "location" from "N2 is special". The plan concedes this in one sentence and then concludes "held where its states differ, whatever the graph". Revise the claim. The quantity that answers M4a's confound is E_own in the selected graphs on its own, against M4a's 12% for the C3 cut there. Cheap improvement: add an arm that shares the own cut's asymmetry, as many weight-stratified edges running *out of* the top-30 into the rest. If those do not erase and the internal ones do, "held among themselves" is shown against a fair control. About one extra arm per genome.

2. **Cut size comes back across groups.** N2's top-30 is close to C3 and encloses about 260 edges. On a shuffled graph 30 neurons may enclose a few dozen. A small own set that fails to erase yields "not shown in the selected graphs" for size, the confound M4b was meant to remove. Before the run: read `own_edges` per group from the smoke, which already records it, and pre-state that E_own and D will be described by own-edge count, and that "not shown" with own sets far below N2's is not evidence against location.

3. **A free check is missing.** The C3 arm on N2 repeats M4a Part 2's C3 arm on the same genomes, roots, input and float64 brain. Its outcomes, and the intact arm's, must equal `part2__N2__*.json` exactly. Assert it in `run_panel`.

4. **Zero own edges.** A genome whose 30 neurons enclose no edge gets empty draws; both arms equal intact and it counts as "not erased" twice, diluting E_own. Say so or exclude it, pre-stated.
