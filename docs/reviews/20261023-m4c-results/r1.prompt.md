chemical edges for 30 ticks erases a separate-states switch more often than edge sets of the same summed anatomical
weight under three fixed schemes (X exterior same count, W core more edges, C core same count from a swap chain). The
plan is `docs/memory/M4C-PLAN.md` (draft 3, agreed by both of you, D361); the code is `scripts/memory_m4/m4c.py`,
`m4c_read.py`, and the after-the-data tables script `m4c_tables.py`.

(all six lower bounds above 0.10). The records are in `runs/memory-m4c/` (census JSONs, `sets.json`, the panel records
`N2__78xx.json`, `readings.json`, `read_run.txt`, `tables.txt`, the logs and the compute record; the `.npz` arrays and
`compute/` are local and not to be committed). Draft 1 of the write-up is `docs/memory/M4C-RESULTS.md`.
