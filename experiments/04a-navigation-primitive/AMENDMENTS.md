# 04a: amendments

Dated amendments to the bound pre-registration go here, never into `PREREGISTRATION.md`, which is a
guarded file: changing it after binding would stop the next stage. This file is not guarded.
An amendment that changes the code (for example fewer generations after an over-limit projection)
also changes the binding commit: the projection is then rerun on the new commit (§8).

None so far.
