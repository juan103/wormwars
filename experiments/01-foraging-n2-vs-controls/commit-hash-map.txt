# WHY THIS FILE EXISTS
#   This repository's git history was rewritten twice before publication, and both rewrites change
#   every commit hash. The run bundles under runs/*/bundle.json record the commit each experiment
#   ran at; those recorded hashes are the ORIGINAL ones and no longer exist here. This file maps
#   them to the commits that finally replaced them, so a bundle can still be traced to its code.
#
#   The two rewrites were:
#     1. Identity. The author and committer fields carried a personal email address, and every
#        commit message carried a session-URL trailer. Both were replaced with a GitHub no-reply
#        address and removed, respectively.
#     2. Data hygiene. One committed file was found to contain a derived form of the connectome's
#        anatomical weights, which this project does not redistribute. It was removed from every
#        commit. It is regenerated deterministically from its seed instead, so nothing is lost.
#
#   Both rewrites happened while the repository was private and before any public push. No
#   published history was rewritten and no clone was invalidated.
#
# WHAT WAS AND WAS NOT CHANGED
#   Changed:   author and committer identity; the session trailer; one removed path.
#   Unchanged: every other file, every author date, every committer date, and the order and
#              parentage of commits.
#

#   <source commit>  <final commit>  <origin>  <subject>
#
#   origin = "original"       the hash as it was before either rewrite; these are the hashes
